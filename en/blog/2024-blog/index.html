2024 平淡生活中的刺

August 25, 2024 · 6 min read
Hao Yiwen

记录 2024 年在全栈移动端探索、AI 转向与日常生活中的阶段性感悟与随笔。

20240325​

经过一个多月的时间，终于看完了 Compose 基础知识篇章，从布局到 ViewModel，再从网络请求到 Room 以及 WorkManager，对 Compose 开发有了一个初步认识，但脑海里还没有把 Android 知识完全连成片。

不积跬步，无以至千里；不积小流，无以成江河。

3 月份了，情绪还是时好时坏。一方面是因为知识储备的焦虑，目前还不能在各个方向独当一面、真正做到从 0 到 1；另一方面，感情里的事情确实对情绪影响很深，很想我们能好好的，但有些要求当下的我或许还做不到。

时间大概会慢慢抚平焦虑，只是心底确实希望能有一个确定的未来，尽管此刻看起来还很遥远。

20240428​

今天写代码时照常使用 ChatGPT 辅助开发，结果抽风严重，在生成 XML 代码时频繁卡死，几乎无法正常使用。

不得不感叹 ChatGPT 实在强大，真心希望服务稳定、不要受限，否则写代码的效率真是大打折扣。好在后续又恢复正常了。

20240607 有感​

马上 25 岁了。7 年前走出家门来到北京，再到如今机缘巧合来到上海，诸多事情萦绕身旁，好在都一步步走过来了。

聊聊目前的技术进展：经过 8 个月对 Android 的系统学习，基础框架已经搭建完毕。虽然还没有经历大量商业项目的洗礼，但核心知识点基本都过了一遍，与年初预期大体一致。

6 月初，在完成 RN 源码编译和 RN 多实例集成后，我拿着 Android App 思考了一个问题：为什么 Android 开发体验很顺手，但在流畅度和细腻度上，iOS 的表现总是更胜一筹？受够了部分场景下的卡顿感后，我决定把 iOS 也彻底补齐，走完整的大前端/全栈路线：

  1. 首选深耕方向：Android / React Native / iOS。
  2. 先花 3 个月系统过完 iOS 开发基础，再花 4 个月潜心打磨双端集成 RN 的工程底座（Android 侧现已交付）。
  3. 随后花 3 个月主攻 Flutter，争取在次年春天收官。去年写过一个月 SwiftUI，当时对多线程和内存管理还不够熟悉，如今有了 Android 基础打底，希望进度能更快一些。

20240704 小记​

从凌晨开始，感觉心脏有些发闷，像是被什么堵住了一样。长期作息不规律加上熬夜加班，身体发出了预警信号，需要好好调养一段时间了——接下来必须在凌晨 1 点前入睡。

关山难越，谁悲失路之人；萍水相逢，尽是他乡之客。

20240722​

今天和往常相似，却又有些不同——仿今日头条 App 终于开发完毕了，我也终于可以腾出手正式切入 AI 领域。相比传统移动互联网的红海，AI 无疑蕴藏着更大的机遇。接下来需要在巩固 Native 开发的同时推进 AI 学习与研究，在两者之间找到平衡。

202408​

8 月是一个燥热的月份，热得让人心慌。以前总觉得把时间往后推，有些问题好像就不会发生；可时间到了，该面对的终归要面对。从春天开始停掉了跑步，很多事情也跟着慢了下来，一时有些迷茫，不知该如何重新找回冲劲。

在技术层面，8 月的主线是 Flutter。Flutter 可以说是声明式 UI 思想在跨端领域的极佳体现，解决了许多 Native 开发痛点，目前仿网易云音乐项目正在稳步推进。另一件棘手的事是 React Native 的 Tree Shaking 难题——尝试调研了早期的 Metro Tree Shaking 方案，实际收益有限，推进难度很大。

20240926​

经过近一年的持续投入，从 Android 到 Flutter 再到 React Native，移动端开发总算整体入门了。接下来最重要的是把学到的技术转化为完整的作品，比如“一问 AI 故事”、仿网易云音乐以及配套后端服务。

与此同时，也是时候正式深入 AI 领域了——深度学习浪潮不过十余年，Transformer 提出也才七年，现在入局依然大有可为。令人惊喜的是，回头看去年 12 月写的项目和配套 Spring Boot 服务，至今依然稳稳运行。

20241007​

国庆假期结束，正式开启新的学习篇章：All in AI。传统技术栈很难再提供破局的杠杆，新的机会一定孕育在新一代技术浪潮之中。

这个国庆虽然偶有争执，但呆子终于提到了人生第一辆车，真心替她开心，希望往后的日子越来越顺遂。假期里彻底放空休息了几天，接下来重新投入开发，但绝不能再透支身体——必须坚持早睡早起，否则熬夜换来的只是低效消耗。

回想 2019 年选专业时，还曾觉得人工智能专业遥不可及、难以落地；短短五年过去，以 LLM 为代表的大模型技术已经在重塑整个世界。

近期主线梳理：

  • 工程开发：React Native、Flutter、Android、Next.js、小程序
  • AI 方向：机器学习理论基础、大模型原理与微调实践

20241020​

走到今天，最重要的已经不只是专业技能本身，而是积极向上的精神面貌与自律的作息。经过一年多的埋头苦学，技术版图已初具雏形；想要真正穿越漫长的黑夜，必须靠健康的体魄与规律的生活支撑，否则一切终归是空中楼阁。

从今天起换挡出发：坚持跑步，保持自律。

20241219​

好久没写日志了。过去半个月一直在攻坚一款同时兼容 Next.js 与 Taro 小程序的高性能复杂日历组件，直到今天终于告一段落，着实累得够呛。

卸下重担，终于又可以开心地投入 AI 研究了！
