# Native 与跨端客户端开发

本专栏系统整理移动端原生开发与现代跨端框架的核心机制、工程集成与性能优化实践：

- **iOS 开发**：Swift、Objective-C、UIKit、SwiftUI、CocoaPods 与 Widget 开发
- **Android 开发**：Kotlin、Jetpack Compose、传统 View 体系、Gradle 构建与后台任务调度
- **Flutter**：Dart 语言特性、自绘渲染机制、隐式/显式动画与混合栈接入
- **React Native**：JSI / Fabric 新架构、Metro 打包器、Expo 工作流与双端原生混合集成
- **HarmonyOS**：鸿蒙分布式架构与跨端生态适配
