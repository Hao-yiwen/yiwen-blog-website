# 人工智能

在深度进入软件开发领域的第三年，我开始思考一件事情：传统的前端和后端开发能干一辈子吗？在此过程中我又能找到自己存在的意义吗？思索良久，我觉得答案是否定的。

传统前端和后端工程体系已经相当成熟，日常更多是在既有范式下修修补补；与此同时，AI 的持续进化正在深刻重塑整个软件开发行业。作为身处其中的开发者，需要主动走出一条虽然陡峭复杂、但上限极高的道路——深入人工智能底层原理与工程实践。

## 专栏导航

- **AI 工程化**：Agentic RAG、文档切分策略、Langfuse 可观测性等落地架构
- **深度学习与大模型**：
  - **深度学习基础**：线性代数与矩阵范数、计算图、Autograd 自动微分、反向传播与参数初始化
  - **优化器与训练技巧**：SGD、Momentum、Adam / AdamW、学习率调度器、梯度裁剪与权重衰减
  - **模型架构演进**：MLP、CNN（LeNet / AlexNet / VGG / ResNet / YOLO）、RNN / LSTM / GRU、Transformer（Attention / RoPE / GQA / FlashAttention / MoE / DeepSeek-V3）与后训练（SFT / DPO / PPO / GRPO）
  - **自然语言处理（NLP）**：分词算法（BPE）、Word2Vec、N-gram、隐马尔可夫与大模型涌现现象
  - **框架与算力平台**：PyTorch 核心机制、Hugging Face 生态、FP8 低精度训练与 GPU 监控
  - **部署与推理**：Scaling Law、分布式训练与推理并行策略、vLLM（PagedAttention / KV Cache）与主流推理引擎对比
- **Python 生态**：现代包管理（`uv` / `conda`）、核心语法特性与科学计算工具栈
