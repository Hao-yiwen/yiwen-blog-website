今天在写代码和研究底层实现时愈发觉得，想要快速提升技术深度，确实要多看源码；如果只停留在口头讨论而不深入代码细节，进步终归太慢。

<!-- truncate -->

现在主流开源框架和语言标准库都有非常详尽的英文注释，看源码遇到困惑时，直接阅读源码注释往往是最准确的一手资料。为了降低英文长注释的阅读门槛，可以配合 IDE 翻译插件辅助阅读。

## IntelliJ IDEA 翻译插件

- [Translation 插件](https://plugins.jetbrains.com/plugin/8579-translation)

## VS Code 翻译插件

- [ChatGPT Comment Translate](https://marketplace.visualstudio.com/items?itemName=kitiho.chatgpt-comment-translate)
- [Comment Translate (GitHub)](https://github.com/intellism/vscode-comment-translate)

### VS Code 使用配置

1. 打开 VS Code 设置：`File -> Preferences -> Settings`（或快捷键 `Cmd/Ctrl + ,`）。
2. 搜索 `ChatGPT Translate` 或 `Comment Translate`，按需配置翻译源即可。
